
## Deployment on Vercel

Connect your GitHub repository at [vercel.com/new](https://vercel.com/new). The repository includes a ready-to-use `vercel.json` configuration.

## Project Structure

- `src/` — React components, data, and entry points
- `src/main.tsx` — Application root component
- `src/data/music.ts` — Track and album data definitions
- `src/components/` — Reusable UI components (Sidebar, AlbumCard, PlaylistView, PlayerBar)
- `vite.config.ts` — Vite configuration
- `index.html` — HTML template
- `package.json` — Dependencies and scripts
- `tsconfig.json` — TypeScript configuration
- `vercel.json` — Vercel build configuration
- `README.md` — Documentation
